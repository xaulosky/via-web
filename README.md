# Vía — sitio migrado a Astro

Este repositorio contiene una migración inicial del sitio estático a Astro.

Instrucciones rápidas:

1. Instalar dependencias:

```bash
npm install
```

2. Levantar servidor de desarrollo:

```bash
npm run dev
```

3. Compilar para producción:

```bash
npm run build
```

Las páginas HTML originales fueron convertidas a `src/pages/*.astro`.
